# 故障排查

按“环境 → 服务 → 模型 → 工具 → 状态”逐层检查，一次只改变一个条件。优先使用小任务重现，不先删除缓存、项目或全部配置。

## 启动与环境

| 现象 | 检查与处理 |
| --- | --- |
| 找不到ms-agent | 激活安装时的Python环境，检查python/pip所在环境 |
| 找不到Node/pnpm | 新终端加载nvm，确认Node 22.22.0+及pnpm 10.17.1 |
| 首次启动很慢 | 查看后端依赖/前端构建进度；不要用未就绪页面判断失败 |
| 页面或CSS缺失 | 使用正常 `ms-agent ui` / `pnpm build` 流程，不绕过样式构建 |
| 端口被占用 | 选择空闲端口，不随意终止其他进程 |

## 模型与流式回复

没有模型列表时确认已添加模型；401/403查凭据和权限，404查模型ID/端点，400查请求参数及输入类型。先移除附件和可选工具测试纯文本，再逐一加入。

流式阶段暂时没有文字，可能仍在生成工具参数或等待审批。查看执行状态；不要同时反复发送相同任务。停止后检查是否已经生成部分产物。

## 文件、历史与草稿

- 历史缺失：核对项目、工作目录、`MS_AGENT_HOME`和所用入口。
- 编辑丢失：检查是否真正保存；页面内草稿不保证跨刷新持久化。
- 文件冲突：先比较磁盘变化，再决定重新加载或覆盖。
- 默认项目恢复提示：先备份，阅读恢复对项目元数据的影响，不盲点确认。

## 工具与扩展

MCP连接错误先查可执行路径、网络、认证和协议；技能不可见先查目录结构、启用状态和作用域。工具权限拒绝应检查规则与确认处理器，而不是修改模型提示绕过。

本地检索需要实际文件根；LSP目录索引不是编译验证；可选向量/解析/视频依赖需装到真正执行任务的环境。

## 提交可复现信息

报告入口、命令或操作顺序、版本/提交、系统和Python/Node版本、脱敏错误、预期与实际结果。保留必要日志和最小测试配置；删除Key、认证头、私人文件、完整请求内容。模型回复质量问题与框架传输/生命周期故障分开描述。
