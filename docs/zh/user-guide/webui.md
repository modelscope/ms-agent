# WebUI 工作台

WebUI把项目对话、工具过程和文件放在同一工作台。先按{ref}`快速开始 <webui>`安装并配置一个模型；本页介绍后续日常操作。

## 开始与继续对话

1. 在左侧选择项目，使用“新建对话”建立会话；未选择自己的目录时可先用Default项目测试。
2. 在输入框下选择模型。新提供方保存后仍需添加模型，并回到对话中选中它。
3. 输入任务，按Enter发送。先使用范围清楚的只读请求，再允许修改文件。
4. 查看流式回复和工具过程；任务结束后继续追问，或从左侧项目历史重新打开会话。

页面刷新后应能找到已保存消息，但未发送的输入与编辑器草稿不能当作持久化记录。模型请求失败时保留任务内容，修复模型设置再重试，不必先删除整个项目。

## 理解执行过程

回复文本、思考内容和工具调用是不同的展示项。参数仍在生成时工具尚未执行；授权提示需要先处理才能继续。状态显示处理中时，查看当前阶段，不把暂时没有新文本误认为没有工作。完成后，过程可能折叠在“已处理”区域；展开它，再展开工具组和某次调用，可以查看参数与结果。

输入框旁的权限选择决定交互方式。默认“总是询问”适合首次使用；批准前确认工具、命令和路径。确认提示中可选择拒绝、仅运行一次或允许后续运行；初次尝试优先逐次确认。生成期间点击输入框旁的停止按钮，中断后可继续发送消息。停止执行后检查已有产物，停止不是撤销。不要为消除提示而给未知项目全部权限。

## 文件与附件

对话附件用于为本次输入提供文件或图片；工作空间中的文件用于持续管理项目产物，两者不是同一入口。上传私有文件前确认模型和服务部署位置。

打开“工作空间”，选择文件预览。Markdown可在预览和源码之间切换；源码编辑后用 **Cmd/Ctrl+S** 保存。文件树的“添加文件”菜单提供新建文件、新建文件夹、上传文件和上传文件夹。下载会保存到浏览器的下载位置。

切换文件时未保存草稿可留在当前页面；刷新前应保存，或关闭编辑器时选择“全部保存并关闭”。其他程序或Agent同时修改文件时，会在重新检查文件后显示“文件已变更”。点击提示并确认“重新加载”可放弃本地草稿、读取磁盘版本；看到冲突提示后仍执行保存可能覆盖磁盘版本，不要连续按保存键来消除提示。

## 项目设置和扩展

项目菜单可以进入设置，查看工作目录、指令、技能/MCP等作用域。全局“设置”中的模型、搜索、个性化与项目选项分工不同，不要假设全局停用和会话未选择是同一种状态。

- [项目与会话](projects-sessions.md)：目录、历史及删除边界。
- [模型设置](model-settings.md)：提供方、模型和默认值。
- [技能与MCP](skills-mcp.md)：安装/连接与启用。
- [记忆管理](memory.md)：查看、编辑及生效时机。

## 离开工作台

关闭网页不一定停止正在运行的后端任务。需要关闭服务时，在启动终端按Ctrl-C；下次重新激活环境并运行 `ms-agent ui`。源代码变更后启动器可能重新构建页面，已有有效构建会复用。

当前工作台不是所有领域项目的统一启动按钮。DeepResearch、CodeGenesis等专用工作流仍按各自[领域应用](../applications/deep-research.md)文档运行。远程部署和无内置登录的边界见[部署](deployment.md)。
