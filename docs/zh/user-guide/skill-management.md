# Skill 安装与更新

在 WebUI 的设置或项目 Skills 面板中管理安装、更新和恢复。安装只下载文件，不执行包内脚本。

## 在 WebUI 中使用

1. 选择 **添加 Skill → 从链接安装**，输入 GitHub 仓库 / 子目录或 ModelScope Skill / 合集链接。
2. 选择全局或项目位置，勾选所需 Skill；如有静态检查提示，查看并确认后安装。同名候选需择一，已安装项不能重复覆盖。
3. 点击 **检查更新**，在 **待更新** 项的详情中预览文件差异并确认。
4. 如需撤回，在详情菜单选择 **恢复旧版**。仅保留最近一次替换前的实际文件，包括本地修改。

出现 **本地有修改** 时，更新或恢复需明确确认覆盖。本地导入的托管 Skill 可在详情中 **关联来源**：内容一致只补记录，不一致需确认备份替换。外部目录中的 Skill 不在原位置升级。

任务或队列运行期间不能更新；结束或停止后可操作。更新后继续原会话，模型会在下一回合收到内部提醒；停止后保留的排队消息恢复时也使用新版。仅检查到“待更新”不会通知模型。

## 来源与版本

| 来源 | 更新规则 |
| --- | --- |
| GitHub 公共仓库 / 子目录 | 分支跟踪新提交，tag 和 commit 固定版本；仅目标 Skill 内容变化才显示待更新 |
| ModelScope Skill | 按仓库 commit 下载；需要认证时，在后端设置 `MODELSCOPE_API_KEY` |
| ModelScope 合集 | 成员可多选安装，失败项单独显示；安装后分别更新和恢复，合集成员变化不会自动增删本地内容 |

应用打开、进入项目或重新可见时，会自动检查全局与当前项目，成功结果缓存 24 小时。可在 Skills 面板的更多菜单关闭，手动检查仍可用；服务关闭时不检查。检查失败保留已有文件与上次结果。
