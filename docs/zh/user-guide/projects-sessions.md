# 项目与会话

项目关联工作目录、指令和资源选择；会话保存一次持续工作的消息与运行记录。一个项目可以有多个会话，不必为每次对话复制目录。

## 打开项目

在WebUI左侧项目区新增项目或打开已有目录。选择目录前确认其中没有不希望Agent访问的资料；远程WebUI中的路径属于服务器。Default项目适合初次试用，不代表当前浏览器电脑的任意文件夹。

给项目一个易辨识的名称，检查实际工作目录后再提交读写任务。项目指令用于持续约定，当前需求放进会话消息。技能和MCP的项目选择见[扩展教程](skills-mcp.md)。

## 管理多段工作

- 用“新建对话”开始独立上下文。
- 展开项目查看历史，点击已有会话继续。
- 使用菜单中的命名/管理操作整理记录，执行删除前阅读确认范围。
- 在TUI中使用 `/sessions` 列出当前项目会话，`/resume <编号或ID>`恢复，`/new`开启新会话。

切换项目会改变工作目录及作用域，不是只改页面标题。不要把一个会话中的未保存文件草稿当作另一个会话的产物。

## 从历史回复分支

在已完成回复下方点击复制按钮旁的 **分支**，保留截至该回复的历史，在新会话继续。新标题依次为 `原标题 (2)`、`原标题 (3)`，历史末尾的分隔线可返回原会话。原会话运行时也可从更早的完整回复分支；未完成或中断的回合不可选。

分支继承历史工具结果、有效摘要和源会话当前选择的模型。打开新会话不改全局默认模型，输入框留空。聊天记录独立，项目文件、配置和记忆仍然共享，分支不是工作目录的快照或回滚。原会话未发送的草稿可在同一标签页切回时保留，刷新后不保留。

## 保存与恢复

已完成消息和会话数据由SDK存储；输入框草稿、未保存编辑器内容有不同生命周期。离开页面前先保存文件。服务重启后重新打开历史可以继续对话，但不会自动重放所有中断的外部操作。

恢复后先询问或查看上一轮已经生成的产物，再决定重试范围，避免重复写入/重复提交外部请求。上下文压缩仍保留原始日志，但模型可能只看到压缩视图。

## 备份与删除

备份应包含应用home中的配置/元数据/会话，以及用户选择的工作目录。删除会话记录与删除项目工作文件不是同一件事；先阅读实际操作确认，不凭名称推断全部数据都会删除或保留。

找不到历史时检查 `MS_AGENT_HOME`、项目目录、所用入口和是否真的提交过消息。不要直接删除存储目录尝试“重置界面”。
