# 模型设置

模型设置有三个步骤：建立提供方连接、添加模型、选择本次对话使用的模型。页面能打开或Key显示“已配置”，都不等于服务调用已经成功。

## 使用内置提供方

1. 打开 **设置 → 模型设置**，选择ModelScope等内置提供方。
2. 点击“编辑”，填写API Key并保存。Key只写入、不回显，未显示明文不代表未保存。
3. 在右侧“添加模型”中选择或搜索提供方实际提供的模型 ID，可另外填写展示名称；列表没有时手动填写。
4. 图片理解选择“自动”按模型能力识别；未知模型默认关闭。确认自定义部署支持图片后可手动开启。
5. 返回对话页，打开输入框下的模型选择器，先找提供方再选模型。

模型展示名称是界面标签，模型ID才发送到服务。不同提供方下同名模型不保证参数与能力相同。

## 自定义端点

“添加提供方”需要唯一ID、Base URL和协议，展示名称可选。OpenAI兼容服务通常使用带 `/v1` 的API根路径；Anthropic协议使用其实际服务根路径。不要把网页控制台URL或完整chat/completions路径随意当作Base URL。

保存提供方后再添加模型。选择协议后检查高级参数，避免将不支持的思考/采样参数传给服务。内置提供方的地址可能不可编辑，需要其他地址时新增自定义提供方。

## 默认值与当前会话

页面顶部可设置默认提供方/模型。对话中的显式选择与恢复旧会话的已存选择不同；恢复已有会话不应被理解为重设全局默认。修改设置后检查输入框下实际显示的模型再发送。

多页面打开时配置可能通过更新通知刷新。若仍看到旧值，先重新打开选择器或刷新页面，避免连续重复添加同一个模型。

## 思考、图片与上下文

支持思考控制的模型可在设置或对话模型名旁选择档位，只显示当前模型支持的选项。会话按模型保留选择；主动修改会同时更新新会话默认值，恢复已有会话只读取其已保存设置。高级 JSON 中的原生思考参数优先，此时快捷选择禁用。

图片理解的“自动 / 开启 / 关闭”可覆盖能力识别。关闭时附件只传路径，不表示主模型已读图；音频、视频、PDF 的模型能力标签也不意味着界面支持原生上传这些格式。

上下文限制可缩小已知模型窗口，或为未知模型设上限；清空恢复默认。输入框圆环、手动压缩与能力数据更新见 [WebUI 工作台](webui.md)，字段含义见[上下文管理](../core/context.md)。

## 错误恢复

| 现象 | 先检查 |
| --- | --- |
| 没有模型可选 | 是否完成“添加模型”，而不只是保存Key |
| 未选择模型 | 回到对话选择器选择实际模型 |
| 401/403 | Key、账户权限、模型额度 |
| 404 | Base URL、模型ID、协议 |
| 参数或读图错误 | 高级参数、supports_vision、服务支持范围 |
| 超时 | 服务可达性、代理、超时预算 |

检查错误不需要把Key截图或贴到对话中。先验证一条无工具文本请求，再增加附件与工具，便于定位问题。

更多字段和路由边界见[模型模块](../core/models.md)。
